01键位认知 · 修饰键含义

Mac 的快捷键文档里全是符号，先认住这五个，后面就全看得懂了。

⌘ Command（最重要，约等于 Win 的 Ctrl）
⌃ Control（次要，类 Unix 操作）
⌥ Option / Alt
⇧ Shift
⇪ Caps Lock
fn Function 键
↩ Return / Enter
⌫ Delete（向左删）
⌦ Forward Delete（向右删，fn+⌫）
⎋ Escape
核心心法：Windows 上的 Ctrl 大部分情况下 = Mac 上的 ⌘ Command。 把这个映射印进脑子，你已经会用 80% 的快捷键了：复制 ⌘C、粘贴 ⌘V、撤销 ⌘Z、保存 ⌘S、关闭 ⌘W、退出应用 ⌘Q。

03必会基础快捷键

每天都会按到的几十个，闭着眼也要会。

快捷键作用
⌘+C / V / X复制 / 粘贴 / 剪切（文本和文件）
⌘+Z / ⇧⌘Z撤销 / 重做
⌘+A全选
⌘+S保存
⌘+F查找
⌘+G / ⇧⌘G查找下一个 / 上一个
⌘+W关闭当前窗口/标签页
⌘+Q彻底退出应用（Mac 关窗口≠关应用！）
⌘+M最小化窗口到 Dock
⌘+H隐藏当前应用（比最小化更干净）
⌥+⌘+H隐藏其他所有应用（只看当前）
⌘+Tab应用切换器（按住 ⌘ 不放，连续按 Tab）
⌘+`同一应用内的窗口切换（数字键左上角那个 `）
⌘+N新建（窗口/文档/Finder 新窗口）
⌘+T新建标签页
⌘+P打印
⌘+,打开当前应用的"偏好设置"（通用规则）
⌃+⌘+Q锁屏
⌘+⌥+⎋强制退出窗口（卡死应用救星）
⌘W vs ⌘Q：这是 Mac 新手最大的困惑。关掉浏览器的窗口，浏览器其实还在运行（看 Dock 图标下面的小点）。要彻底退出按 ⌘Q。

⌘+↑返回上层目录
⌘+↓打开选中项
⌘+[ / ]后退 / 前进
↩ Return重命名（不是打开！）

05复制粘贴 · 高级技巧

Mac 没有 Windows 那种"剪切文件"的直接概念，但有更优雅的方式。

快捷键作用
⌘+C → ⌘+⌥+V移动文件（先 Copy，粘贴时加 Option = 剪切粘贴）
⌘+⌥+⇧+V纯文本粘贴（去掉格式，超常用）
⌘+⌃+空格调出 Emoji 和符号选择器
选中文件 + ⌘+⌥+C复制文件的完整路径到剪贴板
拖文件时按住 ⌥拖动 = 复制（图标会出现 +）
拖文件时按住 ⌘拖动 = 移动（即使到其他磁盘）
拖文件时按住 ⌘+⌥创建替身（快捷方式）
⌘+⌥+D显示/隐藏 Dock
剪贴板历史：系统自带剪贴板只能存一条。建议装 Maccy（免费）或 Paste（付费），按 ⌘⇧V 调出剪贴板历史，效率翻倍。

06截图与录屏

快捷键作用
⌘+⇧+3截全屏
⌘+⇧+4截选区（拖动框选）
⌘+⇧+4 → 按 空格截某个窗口（含阴影）
⌘+⇧+5截图录屏工具栏（全功能，能录屏）

截完图立即标注：截图后右下角会出现缩略图，点一下可以直接画箭头、打码、加文字，比 Win 的截图工具流畅得多。

09文本编辑 · 光标移动

Mac 用 ⌥(按词) 和 ⌘(按行) 替代了 Windows 的 Ctrl+方向键 / Home / End。

快捷键作用
⌥+← / →按"词"跳动
⌘+← / →到行首 / 行尾（= Home / End）
⌘+↑ / ↓到文档开头 / 结尾
加上 ⇧同时选中（所有移动键都可加 Shift 选择）
⌥+⌫删除前一个词
⌘+⌫删除到行首
fn+⌫向右删（= Delete 键）
⌃+A到行首（Unix 风格，终端里超有用）
⌃+E到行尾
⌃+K删除光标到行尾
fn+↑ / ↓翻页（= Page Up/Down）

10Spotlight · 搜索一切

Mac 的灵魂功能，比 Windows 搜索强 10 倍。按 ⌘+空格，然后输入任何东西。

用途怎么用
启动应用输入应用名前几个字母 → ↩
找文件输入文件名
计算器直接输入算式：234*89.5
单位换算100 usd in cny、5 km in miles
查词输入英文单词 → 显示词典释义
查天气weather beijing
网页搜索输入关键词 → ⌘B 用浏览器打开
打开系统设置项输入"显示器"、"声音"等直接到设置页
更强的替代品：装 Raycast（免费）或 Alfred。功能多到爆炸：剪贴板历史、片段（snippets）、窗口管理、快速发邮件……几乎所有 Mac 高手都用。

11触控板手势（Mac 的杀手锏）

如果只看快捷键不学手势，等于只用了半个 Mac。

手势作用
双指点击右键
双指上下滚动页面
双指左右浏览器后退/前进
双指张开 / 捏合缩放
三指上滑调度中心（所有窗口）
三指下滑当前应用所有窗口
三指左右切换全屏应用/桌面
四指张开显示桌面
四指捏合打开启动台（所有应用）
三指拖动文字选中文字（要在系统设置里启用）
用力按（Force Touch）查词典 / 预览链接
开启三指拖移：系统设置 → 辅助功能 → 指针控制 → 触控板选项 → 勾选"使用触控板进行拖移"，方式选"三指拖移"。从此选文字、拖窗口、拖文件全用三指，比按下再拖快 3 倍。

14Windows 习惯改造清单

这些是 Win 用户最容易踩坑的地方，提前知道少走弯路。

1. "关闭"不等于"退出"

Mac 上点红 × 只关窗口，应用还活着。彻底退出按 ⌘Q。看 Dock 图标下方有小点 = 应用正在运行。

2. 没有"剪切文件"，用拖拽或 ⌥V

右键看不到"剪切"。要移动文件：⌘C → ⌘⌥V，或者按住 ⌘ 拖动。

3. Delete 键的位置不一样

Mac 主键盘的 delete（⌫）= Win 的 Backspace（向左删）。
要向右删（= Win 的 Delete）→ fn+⌫。

4. 没有最大化按钮

绿点是"全屏"（独立桌面），不是最大化。
双击窗口顶部标题栏 → 接近最大化。
按住 ⌥ 点绿点 → 真正最大化。

5. 程序坞 ≠ 任务栏

Dock 上的图标是"快捷启动 + 已开应用"混合。最右边的"废纸篓"= 回收站。把文件夹拖到分隔线右侧 = 类似 Win 的"固定到任务栏"。

6. 没有"我的电脑"

Finder 侧边栏点"位置" → 看到所有硬盘。Finder 偏好设置里可以让磁盘显示在桌面上（类似 Win）。

7. C 盘 / D 盘 → 一个根目录

Mac 是 Unix 系统，所有东西都在 /（根目录）下。用户文件在 /Users/你的名字/。

8. 软件安装 ≠ 双击 .exe

Mac 软件常见三种安装方式：
  • .dmg：双击打开后，把图标拖到 Applications 文件夹
  • .pkg：双击一路下一步（少数情况）
  • App Store：直接装（最安全）

9. 卸载软件 = 拖到废纸篓

应用程序里找到 App，拖到废纸篓即可。彻底清理残留配置用 AppCleaner（免费）。

10. 大小写在文件名里不区分（默认 APFS）

和 Win 一样，"File.txt"和"file.txt"算同一个文件。

11. 没有注册表

设置都在 ~/Library/Preferences/ 里，每个应用一个 plist 文件。

12. 全角符号别用

中文输入法的"标点"开成英文标点，避免发出去对方看到"，"和"。"。

15立刻去改的推荐设置

系统默认对 Win 用户不友好的几个地方，建议第一天就改。

✅ Finder 必开

  • 显示 → 显示路径栏
  • 显示 → 显示状态栏
  • Finder 偏好设置 → 高级 → "显示所有文件扩展名"
  • Finder 偏好设置 → 边栏 → 勾选"硬盘"显示在侧边栏

✅ 触控板

  • 系统设置 → 触控板 → 勾选"轻触来点按"（Tap to Click）
  • 系统设置 → 辅助功能 → 指针控制 → 触控板选项 → 启用"三指拖移"
  • 滚动方向"自然"如果不习惯（Win 用户常觉得反），可以关掉

✅ 键盘

  • 系统设置 → 键盘 → 键重复"快"，重复前延迟"短"
  • 开启"按键重复"（默认按住字母会出选字符菜单，写代码人讨厌）
  • 把 Caps Lock 映射成 Control 或 Esc（开发者必做）

✅ Dock

  • 系统设置 → 桌面与 Dock → 关闭"打开应用时显示动画"（更快）
  • 关闭"显示最近使用的应用"（更整洁）
  • 位置可以放左边（像 Win 任务栏放下面也行）

✅ 截图保存位置

默认截图都堆在桌面。按 ⌘⇧5 → 选项 → 改保存到"文稿/截图"文件夹。

✅ 必装软件（Win 移民必备）

  • Raycast 或 Alfred — 启动器，全能
  • Rectangle 或 Magnet — 窗口分屏管理（像 Win 11 一样）
  • Maccy — 剪贴板历史
  • AppCleaner — 彻底卸载
  • The Unarchiver — 解压各种格式
  • IINA — 全能视频播放器（替代暴风/PotPlayer）
  • iStat Menus — 任务栏显示 CPU/内存/网速
  • Karabiner-Elements — 键位改键神器（如把 Caps 改 Esc）

✅ 终端基础（懂代码的看）

open . 在 Finder 打开当前目录
open -a "App Name" 启动应用
pbcopy / pbpaste 命令行拷贝/粘贴
