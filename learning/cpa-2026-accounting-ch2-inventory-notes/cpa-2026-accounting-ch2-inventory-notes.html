第二章 · 存货 · 速记

5 节 · 客观题为主 · 近年均分 ≈ 3 分 · 跨章联动多（所得税 / 债重 / 非货换 / 长投 / 合并）

§1 · 确认与初始计量

1.1 定义 — 最终目的"卖"

✅ 是存货
  • 产成品 / 商品 / 在产品 / 原材料
  • 代制品 / 代修品（视同产成品）
  • 房地产开发企业用于建造商品房的土地使用权
  • 在途物资（已取所有权）/ 发出商品
  • 用于出售的数据资源（2024 新增）
❌ 不是存货
  • 建造固定资产储备的物资 → "工程物资"
  • 受托代销商品（未获控制权，相互抵销）
  • 消耗性生物资产（独立准则）
  • 建造服务合同归集的合同履约成本
📌 确认条件
同时满足 ① 经济利益很可能流入；② 成本能可靠计量。

1.2 初始计量 = 成本 = 采购 + 加工 + 其他

外购：价 + 税 + 费

项内容
价购买价款（不含可抵扣进项税）
税进口关税 / 消费税 / 资源税 / 不可抵增值税
费运输 / 装卸 / 保险 + 入库前合理支出（仓储、包装、合理损耗、挑选整理费）
⚠️ 入库前 vs 入库后
入库前合理支出 → 进存货；入库后仓储费 → 当期损益。
特例：生产中为达下一阶段必需的仓储费 → 计入存货。

采购损耗

情形处理
合理途中损耗计入采购成本（分摊到剩余）
从供货/运输方收回短缺或赔款冲减采购成本
意外灾害 / 待查明暂作"待处理财产损溢"
查明：① 自然灾害 → 营业外支出；② 应由人赔 → 其他应收款；③ 管理原因 → 管理费用

不入存货成本（当期损益）

  1. 非正常消耗的料、工、费（超定额废品、自然灾害损失）
  2. 仓储费用（除生产中必需）
  3. 其他不能归属"目前场所和状态"的支出
  4. 广告营销专用商品：付款时 → 预付账款；取货时 → 销售费用
⚠️ 设计费
特定客户、可直接确定 → 入存货；一般产品 → 当期损益。

商品流通企业进货费用 · 3 种做法

  1. 计入存货采购成本（常规）
  2. 先归集，期末按存销分摊：已售 → 主营业务成本；未售 → 期末存货
  3. 金额小（重要性）→ 发生时直入销售费用

加工取得存货成本

构成包含
采购原材料采购成本
加工直接人工 + 制造费用（生产部门管理薪酬、折旧、办公、水电、机物料、季节性/修理期停工损失、日常修理、停工符合存货确认条件的折旧摊销、符合资本化条件的借款费用、自研/外购无形资产摊销）
其他可直接认定的产品设计费
💡 损耗率
正常损耗 → 计入产品成本；非正常 → 从总成本扣除。
例：100 万零部件，2% 正常 5% 实际 → 产品成本 = 100×(1−3%) = 97 万。

投资者投入

按合同/协议约定价值；不公允则按公允价值，差额计资本公积。

借：原材料（约定/公允）
　　应交税费 — 应交增值税（进项）
贷：实收资本/股本（面值）
　　资本公积 — 资本溢价（倒挤）

§2 · 发出存货计量

2.1 四法对比 — 不得 LIFO

方法原理特点
FIFO 先进先出先入先出可随时结转，繁琐；物价↑ → 利润高估
移动加权每次收货后算新平均及时、客观；收发频繁不适用
月末一次加权月末算一次平均简化；平时账上无单价
个别计价逐一辨认实物流转最准确；珠宝、名画等
公式 · 月末一次加权
单价 = (月初实际成本 + Σ本月进货金额) ÷ (月初数量 + Σ本月进货数量)

2.2 存货成本结转

对外销售商品
借：主营业务成本
　　存货跌价准备
贷：库存商品
对外销售材料
借：其他业务成本
　　存货跌价准备
贷：原材料
生产领用包装物
借：制造费用
贷：周转材料 — 包装物
出借 / 随同产品出售不单独计价
借：销售费用
贷：周转材料 — 包装物
出租 / 随同产品出售单独计价
借：其他业务成本
贷：周转材料 — 包装物

§3 · 期末计量 — 成本与 NRV 孰低

3.1 NRV 两个公式

持有目的NRV 公式
直接出售（产品/材料）= 自身估计售价 − 自身相关税费
需要加工（材料）= 产品估计售价 − 产品相关税费 − 加工成本
⚠️ 估计售价 · 合同价 vs 市价
有合同 → 合同价（优先）；没合同 → 一般市场价。
存货数量 > 合同订购数量：合同部分按合同价，超出部分按市价；不得相互抵销。
存货数量 < 合同订购数量 + 亏损合同 → 还要按"或有事项"确认预计负债。

3.2 NRV 的确凿证据 + 三大考虑因素

  1. 取得确凿证据为基础（成本证据 + NRV 证据）
  2. 考虑持有目的（直接出售 vs 加工）
  3. 考虑资产负债表日后事项影响：已存在情况的新证据 → 调整；单纯市价波动 → 不调整

3.3 材料是否减值 — 看产品

产品 NRV ≥ 成本（产品未贬值）

该材料仍按成本计量，材料不提减值

产品 NRV < 成本（产品贬值）

该材料按 NRV 计量，按差额计提跌价准备

3.4 跌价准备 · 计提方法

方法适用
单项通常按单个存货项目
分类数量多、单价低
总体同地区、相同/类似最终用途，且难以分开计量

3.5 计提 vs 全额计提

需要计提（NRV<成本）
  1. 市价持续下跌且无回升希望
  2. 生产成本 > 销售价
  3. 原材料不适应新产品，市价又低于账面
  4. 商品/服务过时或偏好变化
  5. 其他足以证明减值的情形
全额计提（NRV=0）
  1. 已霉烂变质
  2. 已过期且无转让价值
  3. 生产中已不再需要、无使用价值和转让价值
  4. 其他无价值证明

3.6 计提 / 转回 / 结转 — 会计分录

计提 / 补提
借：资产减值损失
贷：存货跌价准备
转回（金额内）
借：存货跌价准备
贷：资产减值损失
结转（已售）
借：主营业务成本/其他业务成本
　　存货跌价准备
贷：库存商品/原材料
⚠️ 转回 2 限制
① 必须是以前减值的影响因素消失，不是其他因素；② 转回金额以余额冲减至零为限。

§4 · 清查盘点

4.1 盘亏 / 毁损

人祸（计量收发差错 / 管理不善）→ 管理费用

阶段计量差错管理不善
批准前 借：待处理财产损溢
贷：原材料/库存商品		 借：待处理财产损溢
贷：原材料/库存商品
　　应交税费 — 进项税额转出
批准后借：原材料（残料）/ 银行存款（变现）
　　其他应收款
　　管理费用（净损失）
贷：待处理财产损溢

天灾（自然灾害等非常原因）→ 营业外支出

阶段处理
批准前借：待处理财产损溢
贷：原材料/库存商品
批准后借：原材料（残料）/ 银行存款（变现）
　　其他应收款
　　营业外支出（净损失）
贷：待处理财产损溢

4.2 盘盈

  • 自然溢余（如化学品挥发反例）→ 调整库存数量及单位成本
  • 重大会计差错 → 28 号准则处理
  • 其他原因（如日常收发不重大差错）→ 按重置成本冲减管理费用或计营业外收入

5.1 账面余额 vs 账面价值

资产区分
存货、长期股权投资账面余额、账面价值
固定资产账面余额、账面净值（折余价值）、账面价值
无形资产账面余额、摊余价值、账面价值

账面余额 = 原值（不扣备抵）；账面价值 = 账面余额 − 备抵（减值、累折、累摊）后净额。
例：FA 原值 100 − 累折 20 − 固减 10 → 账面净值 80 → 账面价值 70

🎯 高频考点 Cheatsheet

必考 · 5 个 Yes/No
  1. 合理途中损耗 → 计入采购成本（分摊）
  2. 非合理损耗 → 扣除总成本，单独损失处理
  3. 广告营销专用商品 → 销售费用（不入存货）
  4. 不得使用后进先出法
  5. 跌价转回必须是原因素消失且余额冲零为限
必考 · 5 个公式
  1. 外购 NRV = 估售价 − 销税
  2. 加工 NRV = 产品估售价 − 产品销税 − 加工成本
  3. FIFO：按进货顺序逐批结转
  4. 月末加权单价 = (月初成本 + 进货总额) ÷ (月初+进货数量)
  5. 固定资产账面价值 = 原值 − 累折 − 固减
易错 · 跨章联动
  • 所得税：跌价准备 → 可抵扣暂时性差异
  • 债务重组：以存货抵债，按公允价值
  • 非货币性资产交换：换出存货按公允或账面计
  • 长投：以存货投资按公允价确认对价
  • 合并报表：存货内部交易未实现损益抵销
易错 · 持有 vs 抵销

  • "受托代销商品"与"受托代销商品款"相互抵销
  • 消耗性生物资产不属本章
  • 建造合同履约成本不适用本章
